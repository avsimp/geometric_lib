# Overview
**Geometric_lib** provides a ~~limited~~ wide range of functions for *geometric calculations*.
**Geometric_lib** can work with such shapes as: <ins>circle</ins>, <ins>rectangle</ins>, <ins>square</ins> and <ins>triangle</ins>.

# Math formulas realized in project
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
